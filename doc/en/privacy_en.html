Engelsiz Mail Privacy Policy

Last updated: June 1, 2026

1. General Information

Engelsiz Mail is an NVDA add-on developed to help blind and screen reader users perform email operations in an accessible way.

This application allows users to securely connect to their own Google accounts and view, send, reply to, forward, archive, and manage their emails.

2. Data Collected

Engelsiz Mail does not collect, store, sell, rent, or share any personal data with third parties.

The application does not:

  • Collect names, surnames, addresses, or phone numbers.
  • Collect location information.
  • Collect analytics or usage statistics.
  • Collect data for advertising purposes.
  • Track user behavior.

3. Google Account Sign-In

Engelsiz Mail uses the Google OAuth 2.0 authorization system.

Users sign in to their Google accounts directly through Google's secure sign-in system.

Engelsiz Mail does not:

  • See the user's password.
  • Store the user's password.
  • Process the user's password.
  • Send the user's password to any third party.

Authentication is performed directly by Google.

4. Access to Email Data

The application accesses email data through the Gmail API only with the user's explicit permission.

This access is used only to provide the following functions:

  • Listing emails.
  • Viewing emails.
  • Sending emails.
  • Replying to emails.
  • Forwarding emails.
  • Creating and managing drafts.
  • Deleting emails.
  • Archiving emails.
  • Creating and managing archive folders.

This data is used only to perform the requested email-related operation.

5. Data Storage

Engelsiz Mail does not store copies of users' emails on its own servers.

Authorization data used by the application is stored only on the user's own computer in a protected form.

This information is not transferred to third-party systems.

6. Third-Party Services

Engelsiz Mail uses the following services:

  • Google OAuth 2.0
  • Gmail API

When these services are used, the privacy policies of the relevant service providers also apply.

7. Data Security

The developer takes reasonable technical and administrative measures to protect user data.

However, no method of data transmission over the internet can be guaranteed to be completely secure.

8. User Rights

Users may, at any time:

  • Disconnect their Google account from Engelsiz Mail.
  • Revoke the application's access permissions from their Google Account settings.
  • Stop using the application.

9. Changes to This Policy

This privacy policy may be updated when necessary.

The current version will be published in the application documentation and official distribution channels.
